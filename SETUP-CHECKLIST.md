# 10-minute setup checklist

- [ ] Create a GitHub repository named `java-full-stack-daily`.
- [ ] Push all files from this project to the `main` branch.
- [ ] Create an OpenAI API key dedicated to this project.
- [ ] Add GitHub Actions secret `OPENAI_API_KEY`.
- [ ] In **Actions**, manually run **Generate daily lesson** once.
- [ ] Confirm five PNGs appear under `docs/cards/`.
- [ ] If the bot cannot push, enable repository workflow **Read and write permissions**.
- [ ] In **Settings → Pages**, deploy `main` from `/docs`.
- [ ] Open the Pages URL on iPhone Safari.
- [ ] Use **Share → Add to Home Screen**.
- [ ] Done. The scheduled workflow runs every morning at 05:30 Europe/London.
